# User Manual: Chatbot Web App

## Introduction
Welcome to the chatbot web app. This manual explains how to use the page and interact with the chatbot, including saving, loading, renaming, deleting, and exporting conversations.

## Page Overview
The app has three main areas:

1. **Header**: App name and action buttons.
2. **Chat area**: Shows the conversation between you and the bot.
3. **Sidebar / saved chat area**: Displays saved chats and management actions.

### Main Chat Area
- User messages appear on the right.
- Bot messages appear on the left.
- Each message includes a timestamp.
- The chat scrolls automatically as new messages appear.

### Input Area
- Type your message in the input box.
- Press **Enter** or click the **Send** button to submit.
- If the message is empty, it will not send.

### Saved Chat Sidebar
- Saved chats are listed with titles and dates.
- If no chats are saved, the sidebar shows a placeholder message.

## How to Send a Message
1. Click the input field at the bottom of the page.
2. Type your question or prompt.
3. Press **Enter** or click **Send**.
4. Wait for the bot response in the chat window.

## Saving a Chat
1. After chatting, click the **Save Chat** button.
2. The conversation is stored in your browser.
3. A confirmation alert appears when save is successful.

### What Gets Saved
- All user messages
- All bot replies
- The timestamp of each message
- A default chat title based on the current date

## Loading a Saved Chat
1. Find the chat in the saved chat sidebar.
2. Click **Load** next to the conversation.
3. The chat history will replace the current chat window.

## Renaming a Saved Chat
1. Find the conversation in the saved sidebar.
2. Click **Rename**.
3. Enter a new name in the prompt box.
4. Click **OK** to save the new title.

## Deleting a Saved Chat
1. Find the chat you want to delete.
2. Click **Delete**.
3. Confirm the deletion when prompted.

## Exporting a Chat
1. Open a saved chat or keep the active chat loaded.
2. Click the **Export** button.
3. A downloadable text file will be generated with the full conversation.

## Best Practices
- Save chats regularly if you want to keep a record.
- Rename chats with meaningful titles to find them later.
- Use the sidebar to organize conversations.
- Refresh the page only after saving important chats.

## Troubleshooting
### The chat does not send
- Make sure your message is not blank.
- Check that the server is running.
- Refresh the page if the UI appears frozen.

### Saved chats do not appear
- Confirm you saved at least one chat.
- Reload the page to refresh the sidebar.
- Check browser storage settings if saving still fails.

### Error: could not reach server
- Make sure the backend server is running.
- Check the browser console for network errors.

## Notes
- The app stores saved chats locally in your browser.
- Clearing browser storage will remove saved conversations.
- The chatbot works best with short, clear prompts.
